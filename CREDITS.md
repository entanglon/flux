# Credits & Acknowledgements
 
Flux is made possible thanks to the following open-source projects, APIs, and resources:

## Core Media & Playback Engine
- **[mpv](https://mpv.io/)**: High-performance, cross-platform media player core (GPLv2+).
- **[FFmpeg](https://ffmpeg.org/)**: Hyper-fast audio/video decoding and demuxing libraries (LGPLv2.1+).
- **[libass](https://github.com/libass/libass)**: Portable subtitle rendering engine (ISC).
- **[libbluray](https://www.videolan.org/developers/libbluray.html)**: Open-source Blu-ray disc navigation library (LGPLv2.1).
- **[libdav1d](https://www.videolan.org/projects/dav1d.html)**: Extremely fast AV1 decoder (BSD 2-Clause).
- **[libdovi](https://github.com/quietvoid/dovi_tool)**: Dolby Vision metadata parser and processor (MIT).
- **[MoltenVK](https://github.com/KhronosGroup/MoltenVK)**: Vulkan implementation mapped to Apple Metal on macOS (Apache 2.0).

## macOS App Dependencies & Updates
- **[Sparkle](https://sparkle-project.org/)**: Secure, automated software updates for macOS signed with Ed25519 (MIT).
- **[PocketBase](https://pocketbase.io/)**: Lightweight backend powering user authentication, profile sync, and library history (AGPL-3.0).

## APIs & Metadata
- **[The Movie Database (TMDB)](https://www.themoviedb.org/)**: Rich movie and TV show artwork, cast, crew, and metadata.
  - *Disclaimer: This product uses the TMDB API but is not endorsed or certified by TMDB.*
- **[Cinemeta](https://stremio.com)**: Official Stremio catalog and metadata service.
- **[OpenSubtitles](https://www.opensubtitles.com)**: Multilingual subtitle synchronization.
